# Repository agent instructions

Read and follow [docs/agent-instructions.md](docs/agent-instructions.md) before working in this repository. It defines project boundaries, verification, concurrent work, contribution PRs, bug reporting and instruction maintenance.

Keep these instructions current when durable project conventions change. The linked file is the repository-owned copy because project-mirror hosts may regenerate this root file.

Treat every file under `sources/` as synced read-only reference material. Do not edit, rename, move or delete synced files.

End every user-facing message, including progress updates and final responses, with exactly three concise, relevant suggested next steps in a numbered list. Suggestions are not authorization to perform additional work.
