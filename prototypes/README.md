# Proofs of concept

[Room AC Android](room-ac-android/README.md) is the existing working MirAIe integration prototype. Keep it available for reversible, authorized protocol verification. Its SDK pins, package identity, signing material and UI are independent of the new production apps.

Production app code belongs in `apps/room-ac/`. Improvements to a protocol reference do not automatically establish a production architecture or end-to-end support for another device/platform.
