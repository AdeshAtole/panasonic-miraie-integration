# Room AC design proposal

A reviewable design proposal for a lightweight native Android app, prepared 19 October 2026. No production source, installed app or phone state was changed. Nothing was committed or pushed.

Open [index.html](index.html) for a self-contained offline gallery of the locally refined main controller in dark/light themes and 2×2/4×2 widget proposals. Sample room names and readings are synthetic.

## Files

- `*-refined.html`: self-contained local design previews. Controller mode and target drafting are local demonstrations; no AC API is called. Other illustrated controls are visual specimens.
- `*-refined.png`: local user shots at390×844 logical pixels, rendered at2×.
- `*-refined-review.png`: local full-height shots, with footer positioned after the whole content for inspection.
- `controller-light-target-draft.png`, `controller-light-mode-draft.png`: explicit Set/Apply state examples.
- Original `controller-dark.html`, `controller-light.html`, `widgets.html` and their matching un-suffixed PNG/review PNG files are preserved Sleek exports. Those original HTML files use Tailwind CDN and font links; the refined previews and gallery require no external assets.
- `all-screens.png`: original combined Sleek shot; `all-screens-refined.png`: locally refined comparison board.
- [brief.md](brief.md): capability constraints, state contract, information architecture and accessibility requirements.
- [native-plan.md](native-plan.md): Views/RemoteViews implementation approach and release checks.
- [review.md](review.md): changes, validation and remaining design decisions.
- `sleek-request.json`, `run-state.json`, `screens.json`: reproducible non-secret design request and selected version provenance. No credentials or account/device data are included.
