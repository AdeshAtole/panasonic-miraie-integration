RemoteViews & Interaction Specifications

cached Manual Refresh Semantics

No continuous background polling to conserve battery. Tap-to-refresh fires on-demand query. Readback verifies reported state before updating UI.

hourglass_top Pending State Behavior

"Updating..." temporarily replaces timestamp while command is transit. Last-known verified telemetry remains visible until confirmation returns.

report_problem Failure Handling

Preserves previous verified state and shows retry/refresh affordance rather than optimistic false switches that desync physical AC hardware.

tune App vs Widget Boundaries

Temperature steppers (+/-), fan speeds, diagnostics remain exclusively in the full Controller application.
