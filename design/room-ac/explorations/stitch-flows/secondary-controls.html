checklist Behavior Contract & Verification Checklist
  • Draft vs Physical: Steppers and options select a draft state; no hardware command dispatches until the explicit Set action is committed.
  • Mutual Exclusivity: Selecting a capacity cap automatically enforces Powerful: Off; conversely, turning Powerful On revokes fixed capacity.
  • Eco Coupling: Eco confirmation guarantees the user is notified of the 26°C target temperature override before transmission.
  • Async Readback: Applying is shown while awaiting response; readback mismatch surfaces "Not confirmed yet" with Refresh instead of optimistic false checkmarks.
